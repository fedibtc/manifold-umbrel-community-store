# Manifold Community App Store (retired)

> **Manifold Fedimint Guardian is in the official Umbrel App Store.**
> Install and update it from there: https://apps.umbrel.com/app/manifold-fedimint-guardian
>
> This store no longer contains any apps. It stays online only so that
> Umbrels that still have it added keep a valid store.

## New install

1. In Umbrel, open the main **App Store** and search for
   **Manifold Fedimint Guardian**.
2. Select **Install**. It requires Umbrel's **Bitcoin Node** (or Bitcoin Knots)
   on mainnet.
3. Open Guardian and use the app password shown by Umbrel. Follow the
   [Guardian guide](https://manifold.fedi.xyz/guardian-guide.html) to finish
   setup and authorization.

## Already installed from this store?

1. **Do not uninstall Guardian.** Uninstalling deletes its data.
2. Keep using your installed Guardian. It uses the same app ID and data paths
   as the official listing, so it updates from the official App Store with no
   reinstall or data move. Within a few minutes after this store refreshes,
   **Update** appears on the Guardian page in the main App Store.
3. Optional: remove **Manifold** from **App Store → ⋯ menu → Community App
   Stores → Manage**. The installed Guardian and its data stay.

## Existing Fedi Dev installations

The [Fedi Dev store](https://github.com/fedibtc/manifold-umbrel-store) is
separate. Its apps have different IDs.
